# Backend Development Lab

This folder contains practical work completed for the Backend Development course. The experiments progress from HTML and modern JavaScript fundamentals to Node.js, Express.js, server-side templates, cookies and sessions, MongoDB, REST APIs, FastAPI, and Django.

## Technologies Covered

- HTML5 and CSS
- JavaScript ES6
- Node.js
- Express.js
- EJS
- Cookies and Sessions
- MongoDB and Mongoose
- JSON Web Token and bcryptjs
- Python
- FastAPI
- SQLAlchemy and SQLite
- Django and Django ORM
- Django Middleware
