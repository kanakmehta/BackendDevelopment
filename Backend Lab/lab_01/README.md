# Experiment 1: HTML5 Elements

## Aim
To create a web page that demonstrates commonly used HTML5 elements, semantic tags, text formatting, lists, tables, forms, and media-related elements.

## Objective
To understand the structure of an HTML5 document and practice using semantic and form elements to organize content on a web page.

## Technologies Used
- HTML5
- CSS

## Theory
HTML5 provides semantic elements such as `header`, `nav`, `section`, `article`, `aside`, and `footer` that describe the purpose of different parts of a page. It also provides form controls for collecting different types of user input and elements for presenting structured content such as lists and tables.

## Implementation
The experiment is implemented in the `exp_01` HTML file. It demonstrates text formatting, an image, ordered and unordered lists, a description list, a table, and a registration form containing multiple HTML5 input types. CSS is included in the same document to improve readability and layout.

## Project Structure
```text
lab_01/
|-- exp_01
`-- README.md
```

## How to Run
1. Open the `exp_01` file in a web browser.
2. The browser will render the HTML5 elements and the styled page.

## Result
A single HTML5 page is created that demonstrates semantic structure, formatting elements, lists, tables, images, and form controls.

## Conclusion
This experiment provides practical understanding of HTML5 document structure and commonly used elements required to build structured web pages.
