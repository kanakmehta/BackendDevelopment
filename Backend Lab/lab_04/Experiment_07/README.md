# Experiment 7: JavaScript ES6 Todo Application

## Aim
To create an interactive Todo application using modern JavaScript features and DOM manipulation.

## Objective
To practice ES6 concepts such as classes, arrow functions, destructuring, spread syntax, array methods, and event handling.

## Technologies Used
- HTML5
- CSS
- JavaScript ES6
- DOM API

## Theory
Modern JavaScript provides concise syntax and powerful collection methods for managing application state. The DOM API allows JavaScript to create, update, and remove page elements in response to user actions. Event delegation can handle interactions on dynamically generated elements efficiently.

## Implementation
`index.html` provides the Todo interface and loads `app.js`. The JavaScript maintains a `tasks` array, defines a `Task` class, renders tasks dynamically, adds tasks from button or Enter key input, toggles completion state, and deletes tasks. The implementation uses `map`, `filter`, spread syntax, destructuring, arrow functions, and event delegation.

## Project Structure
```text
Experiment_07/
|-- index.html
|-- app.js
`-- README.md
```

## How to Run
Open `index.html` in a web browser.

## Result
The page allows users to add, complete, and delete Todo items dynamically without reloading the page.

## Conclusion
This experiment demonstrates how ES6 JavaScript and DOM manipulation can be combined to build an interactive client-side application and reinforces JavaScript concepts used later in backend development.
