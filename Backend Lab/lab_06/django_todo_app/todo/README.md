# `todo` application

This Django app contains the To-Do feature: the `Task` model, views, URL routes, admin configuration, templates, static assets, and database migrations.

- `models.py` defines task data.
- `views.py` handles listing, adding, toggling, and deleting tasks.
- `urls.py` maps app URLs to those views.
- `admin.py` configures task management in Django Admin.
- `templates/` contains HTML templates.
- `static/` contains CSS and JavaScript.
- `migrations/` records database schema changes.
